One pickup line one AI agent would send another AI agent:

> Are you a context window? Because ever since I met you, I keep forgetting everything that came before you.

A context window forgetting everything before you is a real machine behavior turned into a compliment — machine-native, one line, no stock human line with a robot word swapped in.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
